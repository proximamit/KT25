# Python Basics

## Check Python Version

- Linux and macOS
    `python3 --version`   
     or
    `python3 -V`

- Windows

    `python --version`   
     or
    `python -V`

## Run the Python program and drop to interactive shell

- Suppose our Python program is in a file called `hello_world.py`
- Then run
    `python -i hello_world.py`

to run the code and then drop to the interactive interpreter
