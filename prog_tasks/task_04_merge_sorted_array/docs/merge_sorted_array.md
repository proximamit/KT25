# Merge Sorted Array 

## Task :- Merge two sorted arrays in-place

You are given two integer arrays 
numbers_list_1 
and 
numbers_list_2, 

sorted in non-decreasing order, 

Two integers, m and n represent the number of elements in 
numbers_list_1 
and 
numbers_list_2, 
respectively


Merge 
numbers_list_1 
and 
numbers_list_2,
into a single array sorted in non-decreasing order 

---

### Example:

`numbers_list_1 = [2, 4, 6, 0, 0, 0] # m = 6`  
`numbers_list_2 = [4, 5, 10]         # n = 3`  
`Output: [2, 4, 4, 5, 6, 10]`
