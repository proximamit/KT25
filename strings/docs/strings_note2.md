# Indexing and Slicing in Python Strings


## Indexing 
- **Indexing** means accessing a single character in a string using its 
position.
- **Indexing** - get a single character
- **Slicing** - get a portion of the string
- Indexing starts at **0**
- Negative indexing accesses from the end
- Slicing excludes the **stop index**
- Indexing starts from 0 (called zero-based indexing)
- Each character has a position
- For Slicing, the `stop` index is **not included**

---

## Slicing

**Slicing** means extracting a **substring** (a part of the string).

```python
string[start : stop : step]
```

- **start** - where slicing begins (included)
- **stop** - where slicing ends (excluded)
- **step** - how many steps to jump (optional)
