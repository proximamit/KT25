# Strings

- Strings are sequences of characters
- Strings are one of the fundamental data types  in Python.
- Used to represent text.
- Anything inside quotes is treated as string
- **Immutability** - Once a string is created, its contents cannot be changed.
    i.e. *strings* are **immutable**
- Strings are sequences, which means characters are ordered and can be accessed
 using zero-based indexing and slicing
- Strings in Python are arrays of unicode characters

---

- Strings are created by enclosing characters in
    * Single quotes
    * Double quotes or
    * Triple quotes

single-quoted string example -
```python
str1 = 'hello world'
```

double-quoted string example -
```python
str2 = "Whats up"
```

triple-quoted string with three double quotes example -
```python
str3 = """  This is a string that spans
            multiple lines.  """
```

triple-quoted string with three single quotes example -
```python
str4 = '''  This is a string that spans
            multiple lines.  '''
```
---

- We an display a string with the print() function

```python
print("Hello World!)
```

- Python does not have a character data type.
- A single character is simply a string with a length of 1
- Square brackets can be used to access the characters of the string
