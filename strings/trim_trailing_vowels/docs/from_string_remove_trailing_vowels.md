# Trim Trailing Vowels

- Given a String `str1` that consists of lowercase English letters.
- Return the string obtained by removing all trailing ***vowels*** from `str1`

- The **vowels**  consist of characters 'a', 'e', 'i', 'o', 'u'


## Examples
- Example 1
- Input - str1 = "hello"
- Output = "hell"

---

- Example 2
- Input - str1 = "sunday"
- Output = "sunday"

---

- Example 3
- Input - str1 = "aeiou"
- Output = ""

### Constraints

- 1 <= str1.length <=100 
- `str1` consists of only lowercase English letters
