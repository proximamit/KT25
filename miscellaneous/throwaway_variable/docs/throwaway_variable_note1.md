# Throw Away or dummy Variable _ (the single underscore )


- In Python, the underscore _ is often used as a throwaway variable
- It is a convention that tells readers  
    "this value exists, but I don't care about it."
- It tells that a specific value is intentionally being ignored or  
is irrelevant to the current logic. 
- In the REPL (interactive shell), _ stores the last evaluated result

```python
>>> 10 + 5
15
>>> _ * 2
30
```
